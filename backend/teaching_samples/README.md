# Teaching sample images

Add real PowerPoint slide screenshots to this folder before calling the
temporary teaching endpoint. The prototype deliberately does not include
generated or placeholder screenshots.

Required files:

- `slide_a_original.png` — original slide for `sample_a`
- `slide_a_approved.png` — user-approved target slide for `sample_a`
- `slide_b_original.png` — original slide for `sample_b`
- `slide_b_approved.png` — user-approved target slide for `sample_b`

Each pair should show the same slide before and after the approved edit.
